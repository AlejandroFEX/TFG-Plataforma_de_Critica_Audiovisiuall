# TFG-Plataforma_de_Critica_Audiovisiuall
Trabajo de Fin de Grado de Ingeniería informática de una aplicación que permite puntuar las valoraciones de otros usuarios siendo que estos usuarios reciben una puntuación en base a las valoraciones de sus recomendaciones. El usuario obtendrá más puntos cuanto más alta sea la recomendación y cuanto menos popular sea el producto.
