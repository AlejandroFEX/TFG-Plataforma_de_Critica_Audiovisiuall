# Registros de decisiones de arquitectura (ADR)

Cada decisión de diseño relevante se documenta en un archivo numerado, con este formato:

* **Estado:** propuesta | aceptada | sustituida
* **Contexto:** qué problema o requisito motiva la decisión.
* **Decisión:** qué se ha decidido.
* **Consecuencias:** ventajas, costes y riesgos.

Estos registros dan trazabilidad al diseño (exigida en el método de trabajo del anteproyecto)
y sirven de base para los capítulos de diseño e implementación de la memoria.
